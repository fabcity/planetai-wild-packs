# Surf v1.1 and pack buttons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The surf message covers two days, names every number, recommends a window inside Tomas's hours, and is
answered with buttons, which any pack's rule can now declare, on Telegram and on Now.

**Architecture:** Part B (core) adds a `buttons` column a rule's SQL may return: validated in a new `app/buttons.py`,
stored on `alerts.buttons`, sent as a Telegram keyboard, answered through `/actions` with `choice`, and drawn on Now.
Part A (pack) moves message building wholly into Python: the adapter writes the whole two-day text and the keyboard
into the meta of one summary sensor `surf`, and the rule only gates it to 17:00 and passes it through.

**Tech Stack:** Python 3.9+ stdlib, FastAPI, psycopg, Telegram Bot API, vanilla JS (doors), assert-script tests
(node: `tests/all`; pack: `packs/surf/tests/*.py`, stdlib + PyYAML + duckdb).

**Spec:** `docs/superpowers/specs/2026-11-03-surf-v1.1-and-pack-buttons-design.md` (and v1:
`docs/superpowers/specs/2026-11-02-surf-pack-design.md`).

  If #370 has not merged when it opens, its body says it includes #370's two commits.

  ask?}`. `value` matches `^[a-z0-9:_-]{1,40}$`. `stage` ∈ {acted, acknowledged}, default acted. At most 8 rows of at
  most 4 buttons. Callback data `al:<alert_id>:<value>`.
- Taps refused when the value was not offered (400) or the alert is older than 72 hours (409, "this question has
  closed"). The same (alert, actor, choice) is written once; a later note fills that row's note.

- Good hours are every hour 05–18 passing v1's gates, in runs of at least 2.
- The comfort label never removes a line. "big for you right now" / "grande para ti ahora" / "besar untukmu sekarang".
- Surf `requires: { node: ">=0.91.0" }` stays.
- Node: every new suite gets its `tests/all` line and the count goes up. Suites end in `sys.exit()`, so nothing goes
  below it.

  docs/site changes.

## Review Focus

1. A pack button whose `text` has no entry for the node's locale: it falls back to `en`, then to the first locale.
   It never shows a dict. Test in Task B1.
2. A rule's `buttons` that are invalid (bad value, too many rows, not JSON): the alert is stored and sent without
   buttons, and one warning is logged. Test in Task B2.
3. The node was down all day and the surf summary is from yesterday: no message at 17:00. Test in Task A5.
4. Open-Meteo returns fewer hours for the day after (the series is cut short): day 2 reads "nothing looks good",
   with no exception. Test in Task A4.
5. A Telegram tap from a second chat after the first chat already took that row: it is written, since it is a
   different actor, and that chat's keyboard loses the row. A repeat tap from the same actor writes nothing new and
   the bot still answers the callback. Test in Task B4.
